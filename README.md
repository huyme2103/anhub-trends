# anhub-trends

Public, read-only hosting for the AnHub Last30Days trend feed.

- Feed: <https://huyme2103.github.io/anhub-trends/trends/latest.json>
- Generated by the private pipeline in
  <https://github.com/huyme2103/AnHub> (`workers/last30days/anhub_trends.py`).
- Schema `1.0`, window 30 days, keyless sources only.
- This repository contains no secrets. The feed is public web-trend data
  (titles, summaries and public HTTPS links) produced by Last30Days v3.39.0.
- Do not commit anything except `trends/latest.json` here; the AnHub workflow
  overwrites it on each refresh.
